# 📊 Company Performance Dashboard

An interactive **Company Performance Dashboard** built in Microsoft Excel to analyze sales, customers, products, categories, profitability, and business performance.

## 📌 Project Overview

This project transforms raw sales, product, and customer data into meaningful business insights using **Excel formulas, Pivot Tables, data analysis, and interactive dashboard visualizations**.

The dashboard helps analyze overall company performance and provides insights into:

- 💰 Total Sales
- 📈 Profit & Loss
- 👥 Customer Analysis
- 🌍 Country-wise Performance
- 🛍️ Category-wise Sales
- 📦 Product Performance
- 📅 Sales & Profit Trends
- 💳 Payment Method Analysis
- 👨‍🦰 Male vs Female Customer Sales
- 📊 Day-wise Sales Performance

## 🗂️ Dataset Structure

The workbook contains multiple sheets:

### 1. Sales
Contains transactional sales data including:

- Order ID
- Date & Time
- Product ID
- Customer ID
- Category
- Payment Method
- Selling Price
- Quantity
- Selling Price per Commodity
- Profit

### 2. Products
Contains product-level information such as:

- Product ID
- Product Name
- Company
- Cost Price

### 3. Customer
Contains customer information including:

- Customer ID
- Name
- Gender
- Age
- Country
- Continent
- City

### 4. Dashboard
Provides a visual summary of key business performance metrics and trends.

### 5. Analysis
Contains supporting calculations and analysis used to build the dashboard.

The project focuses on answering questions such as:

1. What are the company's total sales and profit?

3. Which product categories generate the most revenue?
4. Which categories contribute most to profit or loss?
5. How do male and female customers contribute to sales?
6. Which countries generate the highest sales?
7. How does sales performance vary across days of the week?
8. What is the company's customer distribution across different countries?
9. Which payment methods are most commonly used?
10. Which categories/products require better business attention?
